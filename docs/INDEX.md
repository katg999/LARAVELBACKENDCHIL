## Project Overview

This Laravel backend application provides:
- **Healthcare Management System** for schools and health facilities
- **Doctor Appointments** with two-step booking flow
- **Payment Integration** with MarzPay
- **Voiceflow Chatbot** integration for OTP-based authentication
- **Role-Based Access Control** for multiple user types

For general project information, see the main [README.md](../README.md) in the root directory.
